# js_alchemy — ядро «Алхимического Рынка» на JavaScript

Порт математического ядра игры «Алхимический Рынок» с Python/Pygame на **JavaScript (ES6+)**:
те же сущности, та же система крафта, тот же конечный автомат — но без отрисовки,
поэтому ядро работает в Node.js и проверяется автотестами.

**Что внутри:**

1. **Объектно-ориентированная структура** — классы `Element`, `Rect`, `GameField`, `DataManager`
2. **Физика взаимодействия и расстояний** — интенсивность по формуле `I(d) = I₀ · exp(−k·d)`,
   расстояние между элементами — по теореме Пифагора;
   реакция срабатывает только при `I(d) ≥ порога`, а не по голому радиусу
3. **Конечный автомат (FSM) элементов** — состояния `Idle`, `Dragging`, `Crafted`

## Структура

```text
js_alchemy/                # ядро — только логика, без интерфейса
├── package.json            # type: module — запуск ES-модулей в Node
├── recipes.json            # структура рецептов и стартовых элементов (JSON)
├── README.md
├── selftest.js            # самопроверка: 21 проверка (node selftest.js)
└── js/
    ├── constants.js        # все параметры игры и FSM (названия элементов, STATE)
    ├── rect.js             # Rect — порт возможностей pygame.Rect (move/colliderect/collidepoint)
    ├── element.js          # Element — FSM, расстояние Math.hypot, пороговое условие
    ├── data_manager.js     # DataManager — загрузка конфигурации из JSON с валидацией
    └── game_field.js       # GameField — игровое поле и менеджер рецептов крафта
```
## Запуск

Нужен только Node.js 18+ (без установки зависимостей).

```bash
cd js_alchemy

# самопроверка (21 проверка: геометрия, математика, FSM, коллизии, JSON, крафт)
node selftest.js
```

> **Про интерфейс.** В этой версии только ядро — без отрисовки и ввода:
> его можно проверить целиком в консоли, без браузера.

| Аспект | python-game (Python) | js_alchemy (JavaScript) |
|---|---|---|
| Модули | `from element import Element` | ES-модули `import … from './js/x.js'` |
| Прямоугольники | `pygame.Rect` | собственный класс `Rect` (move/colliderect/collidepoint) |
| FSM элементов | логические флаги (`is_dragging`) | объект-перечисление `STATE` + явные переходы между состояниями |
| Срабатывание | проверка коллизии радиуса/прямоугольника | **расстояние + порог срабатывания** `I(d) ≥ 0.15` |
| Затухание | линейное приближение | экспоненциальная формула затухания `I(d) = I₀ · exp(−k·d)` |
| Данные уровня | `recipes.json` + `data_manager.load_game_config` | `DataManager.loadConfig()` с валидацией (`try/catch`) |
| Отрисовка | Pygame flip-цикл в `main.py` | не реализована — ядро от неё не зависит |
## Возможности ядра

- [x] Классы `Element`, `Rect`, `DataManager`, `GameField` — независимые, каждый в своём модуле
- [x] Формула экспоненциального затухания `value0 * Math.exp(-decay * d)` и пороговое условие
- [x] Расстояние по теореме Пифагора (`Math.hypot`)
- [x] FSM: `Idle → Dragging → Crafted`
- [x] Загрузка конфигурации рецептов из JSON с валидацией (`try/catch` + проверка обязательных полей)
- [x] Сортировка ингредиентов при обработке рецептов (порядок соединения не влияет на результат)
