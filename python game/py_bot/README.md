\# Лавка Алхимик — Аналитик игровых сессий



Telegram-бот для игры «Алхимический Рынок». Бот является \*\*сервисом-помощником\*\* игры, а не её копией в чате: игровая логика остаётся в Python/Pygame-приложении, а бот работает с данными, которые игра выгружает.



\## Что умеет бот



| Функция | Описание |

|---------|----------|

| `/top` | Таблица лидеров по капиталу инвентаря на основе базы результатов |

| `/stats \[имя]` | Личная статистика алхимика: сессии, капитал, созданные элементы, лучший результат |

| `/achievements \[имя]` | Проверка достижений и открытых наград игрока |

| `/upload` | Загрузка и верификация файлов сессий (`session\_stats.csv` или `inventory\_save.json`) |

| `/watch` | Подписка/отписка на уведомления о новых результатах в системе |

| `/restart` (или `/start`) | Сброс сессии (имя, подписка, экран) и возврат в главное меню |

| `/menu` | Возврат в главное меню интерфейса |



\## Источники данных



Игра и пользовательские выгрузки взаимодействуют со структурой проекта:



\- `session\_stats.csv` / `inventory\_save.json` — файлы результатов и сохранений из игры.

\- Бот хранит сессии пользователей в папке `py\_bot/sessions/` в виде изолированных JSON-файлов.



Пользователи могут прислать свои файлы через `/upload` — бот проверяет данные, добавляет их в общую память и рассылает уведомления подписчикам.
