# Лавка Алхимика — Аналитик игровых сессий

Telegram-бот для игры «Алхимический Рынок». Бот является **сервисом-помощником** игры, а не её копией в чате: игровая логика остаётся в Pygame-приложении, а бот работает с данными, которые игра выгружает.

## Что умеет бот

| Функция | Описание |
|---------|----------|
| `/top` | Таблица лидеров по капиталу инвентаря на основе базы результатов |
| `/stats [имя]` | Личная статистика алхимика: сессии, капитал, созданные элементы, лучший результат |
| `/achievements [имя]` | Проверка достижений и открытых наград игрока |
| `/upload` | Загрузка и верификация файлов сессий (`session_stats.csv` или `inventory_save.json`) |
| `/watch` | Подписка/отписка на уведомления о новых результатах в системе |
| `/restart` (или `/start`) | Сброс сессии (имя, подписка, экран) и возврат в главное меню |
| `/menu` | Возврат в главное меню интерфейса |

## Источники данных

Игра и пользовательские выгрузки взаимодействуют со структурой проекта:

- `session_stats.csv` / `inventory_save.json` — файлы результатов и сохранений из игры.
- Бот хранит сессии пользователей в папке `py_bot/sessions/` в виде изолированных JSON-файлов.

Пользователи могут прислать свои файлы через `/upload` — бот проверяет данные, добавляет их в общую память и рассылает уведомления подписчикам.

## Архитектура

```
py_bot/
├── bot.py         # Точка входа, хендлеры команд/callback, FSM
├── session.py     # Stateless JSON-сессии по user_id (sessions/<id>.json)
├── analytics.py   # Парсинг данных, рекорды, статистика, ачивки, верификация
├── keyboards.py   # Инлайн-клавиатуры главного меню и управления
├── config.py      # Токен бота, пути, параметры логирования
├── requirements.txt
└── sessions/      # Директория изолированных сессий пользователей
```

- **Stateless**: состояние пользователя (имя, подписка, id экрана) хранится в `sessions/<user_id>.json` и переживает перезапуск бота.
- **FSM** (aiogram 3): состояния `MENU`, `WAIT_FILE`, `WAIT_NAME`.
- **Антифлуд**: интерфейс динамически обновляется на одном экране через `edit_message_text` — id сообщения-экрана и его чат хранятся в сессии; ошибки `message is not modified` перехватываются; новые сообщения отправляются только для уведомлений.
- **Верификация**: загружаемые результаты проверяются на корректность структуры и типов данных перед добавлением в общую базу.

## Проверка функционала

### Живая проверка в Telegram

Откройте чат с ботом (`@aboribauri_bot`) и пройдите по сценарию:

| Действие | Ожидаемый результат |
|---|---|
| `/start` | Приветствие и главное меню с инлайн-кнопками, сброс состояния через `state.clear()` |
| «🏆 Топ игроков» или `/top` | Таблица лидеров по капиталу; **сообщение-меню редактируется на месте (без спама в чат)** |
| «📊 Моя статистика» или `/stats` | Запрос ввода имени алхимика в чат |
| отправить текст `АлхимикИван` | Вывод статистики: сессии, капитал, лучшие показатели |
| «🔄 Сменить имя игрока» | Повторный запрос ввода нового никнейма для поиска |
| «🏅 Достижения» или `/achievements` | Список открытых наград по текущему имени |
| «📤 Загрузить результаты» или `/upload` → прислать файл | Уведомление об успешной верификации и добавлении записей |
| «🔔 Уведомления» или `/watch` | Переключение статуса подписки в сессии (`true/false`) |

## Доступные команды в чате

- `/start` — Запуск и главное меню
- `/menu` — Возврат в меню
- `/top` — Рейтинг по капиталу
- `/stats` — Статистика игрока
- `/achievements` — Просмотр наград
- `/upload` — Загрузка файлов данных
- `/watch` — Подписка на уведомления
